# HAMBONO site / موقع حامبونو
1. ضع ملفات اللعبة داخل مجلد `downloads/`:  `HAMBONO_WINDOWS.zip` و `HAMBONO.apk` (استخرج الـ apk من HAMBONO_ANDROID.zip).
   Put the game files in `downloads/`: `HAMBONO_WINDOWS.zip` and `HAMBONO.apk`.
2. `npm install` ثم `ADMIN_PASSWORD=كلمة_سر_قوية npm start`
3. الموقع: http://localhost:3000  —  لوحة التحكم: http://localhost:3000/admin.html
(كلمة المرور الافتراضية hambono2026 — غيّرها قبل النشر / change it before deploying.)
